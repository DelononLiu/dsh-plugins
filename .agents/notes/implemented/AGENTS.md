# AGENTS.md — Implemented Agent Notes

这些 note 记录**已落地的决策**。遵循根 [AGENTS.md](../../../AGENTS.md) 与 [Agent Note 格式](../README.md)。

## 保持 implemented note 与现状同步

**路径、符号、默认值、机制随实际变更更新**——在改动它们的同一变更里完成：原地重写过期事实，不追加变更历史。

当已落地的 note 不再可能指导未来工作时，按 `.agents/notes/README.md` 的归档规则归档（`archived/`），而不是继续维护。

### 这不是改写*决策*的许可

- **事实层面**（路径、名字、结构）可原地更新。
- **决策反转**需要新 note 并交叉链接，旧 note 保留为被取代记录。
- 完全被取代的旧 note 只能通过 README 里的合并规则删除（先保留全部独有理由/备选/后果，修复入链）。
