# Agent Note: ConsolePanel 结构收敛（4 页签 + 操作内联）

Status: implemented

## Problem

ConsolePanel 页签膨胀到 6 个（总览/实例/主机守护/部署主机/升级/日志），其中
「升级」只是实例的一个批量操作、「部署主机」只是主机引导的一个动作——各自独立
成页签浪费导航空间、割裂操作流。

## Decision

页签收敛为 **4 个**：总览 / 实例 / 主机 / 日志（用户拍板：总览实例无问题，
升级/部署不独立，主机页丰富）。

- **实例页**：内联「批量升级」面板（toggle 展开：勾选下方实例 → 目标版本 →
  升级所选(n) → 结果日志；展开时清空上次勾选；本端不可选；收起按钮）。原独立
  upgrade 页签删除。
- **主机页**：原名「主机 / 守护」→ **「主机」**；内联「＋ 部署新主机」面板
  （toggle 展开：两级流程说明 + SSH 表单 → 生成引导命令 → 命令序列/步骤图/
  复制全部）。原独立 deploy 页签删除。
- 日志保留独立页签（信息密度高）。

## Consequences

- 导航 4 项：▤总览 ☰实例 ⛁主机 ⎙日志。
- 升级/部署从"切页签"变为"同页展开面板"——上下文不丢、操作即所见。
- dsh-console client 仅 UI 结构变化，host/typert 契约不变。
- 浏览器实测：4 页签渲染 ✓；实例页批量升级展开 ✓（勾选/目标/执行）；主机页
  部署新主机展开 ✓（说明/表单/生成按钮）。
