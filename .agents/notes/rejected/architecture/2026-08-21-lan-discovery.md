# Agent Note: 局域网自动发现（否决）

Status: rejected

## Problem

多实例部署时是否需要在局域网内自动发现彼此（mDNS/广播）。

## Decision（否决）

**不做局域网自动发现**。实例发现 = **agent 主动注册 + console 已知地址列表**（主机登记时配置地址）。理由：
- 本发行包是"控制面集中"模型：console 是唯一控制面（单点），所有主机经引导后**主动注册**，无需互相发现；
- mDNS/广播增加协议面与跨子网不确定性（社区 dsh-devices 也写明 mDNS 不跨子网）；
- 小团队主机数少，手动登记地址成本可忽略。

## Alternatives

- mDNS/广播自动发现——否决：多一个协议面，跨子网不可靠，与"集中注册"模型重复。
- 纯手动维护（无注册）——否决：agent 主动注册是心跳/档案的基础，必须有。

## Consequences

- 部署链路 = SSH 引导 → agent 主动注册（无发现环节）；§9 对应项已勾除。
